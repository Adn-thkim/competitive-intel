# Worked Example — `positioning_map` × 토스 트래블카드

> - **목적**: Rubric `docs/reference/report_taxonomy.md` §2-6(포지셔닝 맵)의 추상 기준이 트래블카드 도메인에서 어떻게 구체화되는지를 시연합니다.
> - **도메인 슬러그**: `consumer_travel_card_kr`
> - **자사 상품**: 토스 트래블카드 (`own_toss_travel_card`)
> - **분석 방향**: `mixed` (marketing 전략 + product_dev 보완 영역 식별)
> - **데이터 입력 (흐름 B, Output 인용)**:
>   - comparison_matrix(정량 비교) → X축·실제(positioning) 좌표 산정
>   - reaction_insight(사용자 인식) → Y축·인식(perceptual) 좌표 산정
> - **흐름 분류**: mid 노드 (흐름 A 자체 feature ✗, 흐름 B만 사용). 본 결과는 executive_summary로 흐름 B inline 인용됩니다.
> - **스냅샷 시점**: 2026-05-19
> - **작성일**: 2026-05-19

---

## 1. 적용된 Rubric §2-6 항목 (요약 인용)

- **리포트 목적**: 5개 카드의 실제 속성(positioning)과 사용자 인식(perceptual)을 좌표 평면에 동시 배치하여, 차별점·격차·시장 white space를 한 페이지에서 시각화합니다.
- **표준 출력 단위**: `(card_id, x_actual, y_actual, x_perceived, y_perceived, persona, snapshot_at)` 7-tuple.
- **축 선택 (4단계)**: (1) 고객 의사결정 기준 수집 → (2) 빈도·중요도 가중 → (3) 상관 회피 → (4) 페르소나별 검증.
- **평가 루브릭**: 5개 카드 모두 좌표 산정(필수) / 페르소나별 다중 뷰 ≥ 2 / Aaker 3조건(resonate·differentiate·reflect) 평가 / white space 1개 이상 식별 / "실제 vs 인식" 격차 카드 1개 이상 식별.
- **나쁜 출력**: 축 선택 근거 누락, 단일 페르소나 평균화, white space 미식별, 실제와 인식 구별 없이 단일 좌표만 표기, 점유율 없이 bubble size 자의 부여.

## 2. 축 선택 — §1-4 4단계 적용

**1단계 (의사결정 기준 수집)**: reaction_insight ABSA aspect 빈도 상위 7개 — `fee_perception`(832회) · `app_ux_quality`(654회) · `additional_benefit`(412회) · `customer_support`(287회) · `atm_availability`(198회) · `social_features`(153회) · `exchange_convenience`(120회).

**2단계 (빈도·중요도 가중)**: 빈도 + 매체 비교 노출 빈도 결합 점수 상위 2개 → **수수료 부담 종합** (1순위, X축 후보) · **부가 혜택 풍부도** (2순위, Y축 후보).

**3단계 (상관 회피)**: 두 축의 상관계수 = -0.42 (음의 상관, 일반적으로 저비용 카드는 부가 혜택이 적음). 절댓값 < 0.7 임계치 내라 사용 가능.

**4단계 (페르소나 검증)**:
- 단기 여행자(4박 일본): 두 축 모두 적합. 사용.
- 장기 체류자(3개월 유럽): X축 적합. Y축은 "ATM 호환성"이 더 적합 → 페르소나 2 뷰에서 축 변경 권장.
- 디지털노마드(다국가 순회): X축이 "통화 폭"으로 재정의 필요 → 페르소나 3 뷰는 별도 산출 (본 worked example에서는 페르소나 1·2만 시연).

## 3. Positioning Map — 페르소나 1: 단기 여행자 (4박 일본)

**축 정의**

- X축: 수수료 부담 종합 (0 = 가장 낮음 ↔ 100 = 가장 높음). comparison_matrix `re_exchange_fee_rate` + `exchange_fee_primary_currencies` + `overseas_payment_fee_exempt` + `atm_fee_free_count_monthly` 가중 합산.
- Y축: 부가 혜택 풍부도 (0 = 거의 없음 ↔ 100 = 매우 풍부). comparison_matrix `lounge_benefit_scope` + `cashback_or_mileage_rate` + 여행자보험 + 컨택리스 혜택 합산.

**좌표 (실제 positioning, mock 정량 계산)**

| 카드 | X (수수료 부담) | Y (부가 혜택) | 4사분면 |
|---|:-:|:-:|:-:|
| 토스 트래블카드 | 8 | 12 | 좌측 하단 (가성비형) |
| 트래블월렛 | 22 | 28 | 좌측 하단 (가성비형) |
| 하나 트래블로그 | 38 | 78 | 우측 상단 (프리미엄) |
| 신한 SOL트래블 | 45 | 82 | 우측 상단 (프리미엄) |
| KB국민 트래블러스 | 28 | 25 | 좌측 하단 (가성비형, 한시) |

**ASCII 시각화 (X축: 수수료 부담 →, Y축: 부가 혜택 ↑)**

```
부가 혜택 ↑
  100 ┤
      │
   80 ┤                                     ● 신한 SOL
      │                              ● 하나 로그
   60 ┤                            ┃
      │                            ┃  ← 우측 상단(프리미엄)
   40 ┤    ┌─── white space ───┐  ┃
      │    │   (좌측 상단,        │  ┃
   20 ┤    │   진입 시 강력)      │  ● KB
      │    │                     │  ● 월렛
      │    │ ● 토스               │
    0 └────┴─────────────────────┴────────────────→
        0      20      40      60      80     100
                 수수료 부담 종합 →
```

**4사분면 해석**

- **좌측 상단 (저비용 + 고차별)**: white space. 진입 시 강력한 1위 가능하나 부가 혜택 운영 비용으로 가성비 메시지가 희석될 위험.
- **우측 상단 (프리미엄)**: 하나 트래블로그·신한 SOL 점유. "라운지·적립을 위해 약간의 수수료를 부담하는" 사용자에 적합.
- **좌측 하단 (가성비형)**: 토스·트래블월렛·KB 점유. 토스가 가장 좌측(저비용 극단)에 단독 위치.
- **우측 하단**: 비어 있음. "고비용 + 저차별"은 시장 매력 없는 사분면.

**핵심 발견**

- 토스 트래블카드는 좌측 하단의 **극단 좌측(X=8)** 에 단독 위치. "수수료 부담 최저"의 시장 지위 확보.
- 트래블월렛(X=22, Y=28)과의 X축 격차가 14점으로, 단순 "수수료 0원" 메시지로는 차별이 부족. **재환전 0원·결제한도 5천만원** 같은 구체 메시지로 격차를 사용자에게 인지시켜야 함.

## 4. Perceptual Map — 페르소나 1 인식 좌표 (사용자 만족도·인식 기반)

**축 정의**

- X축: 사용자가 인식하는 수수료 우위 (reaction_insight `fee_perception` aspect positive 비율 → 100 - positive%로 환산해 "체감 부담"). 낮을수록 좌측.
- Y축: 사용자가 인식하는 부가 가치 (reaction_insight `additional_benefit` aspect positive 비율).

**좌표 (perceptual, reaction_insight worked example §2 기반)**

| 카드 | X (인식 수수료 부담) | Y (인식 부가 가치) | 실제 좌표(§3)와의 격차 |
|---|:-:|:-:|---|
| 토스 트래블카드 | 8 | 45 | X 동일 / **Y +33 (인식 우위)** |
| 트래블월렛 | 11 | 52 | X -11 (인식 우위) / Y +24 (인식 우위) |
| 하나 트래블로그 | 15 | 81 | X -23 (인식 우위) / Y +3 (거의 동일) |
| 신한 SOL트래블 | 28 | 72 | X -17 (인식 우위) / Y -10 (인식 열위) |
| KB국민 트래블러스 | 25 | 38 | X -3 / Y +13 (인식 우위) |

**핵심 발견 — 실제 vs 인식 격차**

- **토스의 부가 가치 인식이 실제보다 높음 (Y +33)**: 실제 부가 혜택은 12점에 불과하나 사용자 인식은 45점. 이는 **"수수료 0원"이 부가 가치로 인식되는 효과**입니다. 마케팅 메시지가 효과적으로 작동 중.
- **신한 SOL트래블의 부가 가치 인식이 실제보다 낮음 (Y -10)**: 라운지·컨택리스 같은 실제 혜택이 사용자에게 충분히 전달되지 않음. 마케팅 메시지 강화 필요.
- **하나 트래블로그의 수수료 인식이 실제보다 좋음 (X -23)**: 실제 수수료는 중간 수준이나 사용자는 "수수료 부담 낮은 카드"로 인식. 통화 다양성 메시지가 수수료 인식까지 확장됨.

## 5. Positioning Map — 페르소나 2: 장기 체류자 (3개월 유럽)

**축 재정의 (페르소나 검증 4단계 결과)**

- X축: 수수료 부담 종합 (페르소나 1과 동일)
- Y축: **ATM 호환성 + 통화 폭** (장기 체류 시 결제·인출 안정성)

**좌표**

| 카드 | X (수수료) | Y (ATM·통화) | 4사분면 |
|---|:-:|:-:|:-:|
| 토스 트래블카드 | 8 | 35 | 좌측 하단 |
| 트래블월렛 | 22 | 65 | 좌측 상단 |
| 하나 트래블로그 | 38 | 92 | 우측 상단 |
| 신한 SOL트래블 | 45 | 55 | 우측 중간 |
| KB국민 트래블러스 | 28 | 58 | 좌측 상단 |

**핵심 발견**

- 페르소나 2에서는 **토스가 좌측 하단(저비용·저ATM편의)** 으로 이동, 트래블로그가 압도적 우측 상단을 점유. 장기 체류자에게는 토스의 수수료 우위가 ATM 호환성 약점을 상쇄하지 못함.
- 장기 체류자 페르소나에서 토스의 액션은 ATM 네트워크 강화(product_dev) 또는 "단기 여행자 1순위" 메시지로 페르소나 재정의(marketing).

## 6. Aaker 3조건 평가

| 카드 | Resonate (타겟 니즈 공명) | Differentiate (차별성) | Reflect (자사 역량 정합) | 종합 |
|---|:-:|:-:|:-:|:-:|
| 토스 트래블카드 | 4/5 | **5/5** (재환전 0원 단독) | 5/5 (토스 앱 통합 역량) | **4.67** |
| 트래블월렛 | 5/5 (소셜 차별) | 4/5 | 4/5 | 4.33 |
| 하나 트래블로그 | 5/5 (장기 체류자) | 4/5 | 5/5 (하나금융 통합) | **4.67** |
| 신한 SOL트래블 | 4/5 | 3/5 | 5/5 | 4.00 |
| KB국민 트래블러스 | 3/5 (한시 의존) | 2/5 | 4/5 | 3.00 |

토스와 하나 트래블로그가 공동 최고점. 단 토스는 페르소나 의존성이 강해(페르소나 1에서 우위 / 페르소나 2에서 열위), 단일 점수보다 페르소나별 분리 점수가 의미 있음.

## 7. 평가 루브릭 점수 산정

- **5개 카드 좌표 산정**: 5/5 — 페르소나 1·2 모두 5개 카드 완료.
- **페르소나별 다중 뷰**: 2/2 (필수) — 단기 + 장기. 디지털노마드 옵션은 별도 작성 가능.
- **Aaker 3조건 평가**: 5/5 카드 모두 평가 완료.
- **white space 식별**: 1건 (페르소나 1 좌측 상단). 1건 이상 기준 통과.
- **실제 vs 인식 격차 카드 식별**: 3건 (토스 +Y33 / 신한 -Y10 / 하나 -X23). 1건 이상 기준 통과.
- **종합 점수**: **5.0 / 5.0** — Rubric §2-6 기준 통과.

## 8. Anti-pattern 회피 사례

본 도메인의 5가지 함정과 회피 방식은 다음과 같습니다.

- **축 자의성 함정**: §2에서 4단계 절차를 명시 적용해 축 선택 근거를 투명화. 상관계수 검증·페르소나 검증을 명시.
- **단일 페르소나 평균화**: 페르소나 1·2를 별도 맵으로 분리. 페르소나 1에서 토스 우위가 페르소나 2에서 역전되는 사실을 §5에서 명시.
- **점유율 없는 bubble size 자의 부여**: 모든 카드를 동일 크기 점으로 표시. bubble size 표현은 점유율·매출 데이터 확보 시까지 보류.
- **실제·인식 단일 표기 오류**: §3 positioning과 §4 perceptual을 별도 맵으로 분리하여 격차를 시각화. 단일 좌표만 표기하면 마케팅 액션 기회를 놓침.
- **시간 차원 누락**: 헤더 메타데이터에 **스냅샷 시점: 2026-05-19** 명시. KB의 한시 프로모션 만료(2025-12-31)는 본 시점에 이미 종료, 좌표에 반영.
